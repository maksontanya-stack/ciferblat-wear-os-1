# Galaxy Watch Lab

`Galaxy Watch Lab` — локальная лаборатория визуальной проверки циферблата для Samsung Galaxy Watch на Wear OS. Она не требует передачи изображения или APK в сеть.

## Что проверяет

- 22 экранных профиля: Galaxy Watch4/4 Classic, Watch5/5 Pro, Watch6/6 Classic, FE, Watch7, Ultra, Ultra (2025), Watch8/8 Classic, Watch9 и Ultra2;
- масштаб исходного макета для каждой физической матрицы: 396, 432, 438, 450, 480 и 498 пикселей;
- попадание ярких элементов за границу круглого дисплея и запас до края;
- готовность чек-листа для AOD, полей данных и испытания на реальном устройстве;
- экспорт JSON-отчёта, который можно приложить к задаче или релизу.

Watch4–Watch7 не получают совместимость с WFF v4 только по названию модели: её определяет фактически установленная версия Wear OS. WFF v4 требует Wear OS 6 / API 36. Watch8 работает с Wear OS 6, Watch9 и Ultra2 — с Wear OS 7.

## Запуск интерфейса

В корне репозитория выполните:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/lab/`. Нажмите «Открыть PNG/JPG» или перетащите скриншот/макет. По умолчанию открывается квадратный тёмный макет `design/dark-450.png`.

Жёлтая окружность — безопасная зона: элементы не должны пересекать внешний круг экрана. Выберите модель слева, отметьте выполненные проверки и скачайте JSON-отчёт.

## Пакетный прогон

```sh
python3 scripts/watch_lab.py --image design/dark-450.png --output lab/reports
```

Команда создаёт PNG с безопасной зоной для каждого профиля и `report.json`.

## Граница достоверности

Galaxy Watch Lab воспроизводит разрешение, круглую форму и масштаб. Samsung не предоставляет локальный эмулятор, идентичный каждой версии One UI Watch, её поставщикам пульса/погоды, датчикам и энергопотреблению. Перед серийным выпуском нужно пройти на одном реальном устройстве каждой группы разрешений: 396, 432, 438, 450, 480 и 498 пикселей.
