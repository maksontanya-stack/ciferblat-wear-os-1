Обновление 1.2-preview.4 — Samsung Galaxy Watch4 Classic 46 мм

Эта сборка предназначена для ваших часов с Android API 36 (Wear OS 6). Установщик проверяет версию перед установкой. Старый циферблат удалять не нужно; подпись APK сохранена.

УСТАНОВКА НА WINDOWS
1. Полностью распакуйте wearos1-install.zip в новую папку.
2. Подключите часы и компьютер к одной Wi-Fi сети.
3. На часах включите «Параметры разработчика → Беспроводная отладка». Оставьте этот экран открытым.
4. На прежнем компьютере запустите update.cmd.
5. Введите текущие IP-адрес:порт с ГЛАВНОГО экрана беспроводной отладки. Порт из окна сопряжения не подходит. После переключения отладки порт может измениться.
6. Дождитесь Success. Вернитесь на циферблат и откройте «Настроить» сначала на самих часах. Затем проверьте Galaxy Wearable на телефоне; если приложение осталось на прежнем экране загрузки, закройте его и откройте снова.
7. После проверки выключите беспроводную отладку.

Если компьютер больше не сопряжён с часами, запустите install.cmd и выполните сопряжение. Порт сопряжения и порт подключения — разные.
На macOS/Linux: bash install-macos-linux.sh.

ПОДПИСИ И ИСТОЧНИКИ
В настройках по-прежнему выбираются светлая/тёмная тема и источники для пяти секторов. Добавлены пять пунктов «Подпись»: верх, слева сверху, слева снизу, низ, справа снизу.

По умолчанию выбран режим «Авто»: используется короткое название от источника. Если источник не передал название, показывается запасная подпись сектора — ПУЛЬС, ПОГОДА, ЭТАЖИ, ЗАРЯД или ШАГИ. Для погоды сохраняется композиция со значком и температурой.

Если вы сменили показатель, а его источник передаёт только число без названия, выберите соответствующую «Подпись» вручную, например «ВЫСОТА». Опция «Только значение» убирает подпись. Выбранная вручную подпись имеет приоритет; «Авто» возвращает название от источника. Циферблат не может определить смысл числа, если источник не передал название.

ЕСЛИ НАСТРОЙКИ ПО-ПРЕЖНЕМУ ЗАВИСАЮТ
Не удаляйте циферблат и не сбрасывайте часы. При включённой беспроводной отладке запустите diagnostics.cmd, введите текущие IP:порт и выполните подсказку: откройте настройки, дождитесь зависания, нажмите Enter в окне компьютера. Рядом появится watchface-diagnostics.zip. Его можно просмотреть и передать для разбора. Скрипт сам ничего не отправляет и не меняет настройки часов.

Внешний вид: геометрия дуг, масштаб и штриховка цифр, шрифт, обе подложки, отметки и подчёркивание даты сохранены. Проверка эмулятора Wear OS 6 не заменяет проверку редактора Galaxy Wearable на прошивке Samsung.

ПРОВЕРКА ПОДТОРМАЖИВАНИЙ
Если после обновления задержки сохраняются, запустите performance.cmd в этой папке. Введите IP:порт, оставьте циферблат на экране и нажмите Enter. После первого замера нажмите Enter ещё раз, откройте настройки на часах и листайте страницы около 10 секунд. Скрипт сохранит watchface-performance.zip: нагрузку процессов, расход памяти, доступную статистику кадров и журнал ошибок. Просмотрите архив перед отправкой. Настройки часов не меняются, данные автоматически не отправляются. Статистика кадров может быть недоступна для системного движка; это не означает отсутствие задержек.

В этой версии общая разметка радиальных полей используется для обеих тем; ширина текста для подбора размера вычисляется один раз при обновлении данных. Размер описания уменьшен с 2 584 643 до 919 003 байт, число текстовых блоков — с 403 до 203. Эти числа характеризуют сложность описания, а не FPS или скорость конкретных часов. Геометрия, изображения цифр, текстуры и набор настроек сохранены.
