# Установка на Galaxy Watch4 Classic 46 мм

Требуется Wear OS 4 или новее. Если часы давно не обновлялись, сначала обновите их ПО через Galaxy Wearable. APK устанавливается **на часы**, а не на телефон.

## Самый короткий путь — с компьютера

1. Скачайте архив [wearos1-install.zip](https://github.com/maksontanya-stack/ciferblat-wear-os-1/releases/download/v1.0.0/wearos1-install.zip) и **извлеките его целиком**.
2. Подключите часы и компьютер к одной обычной Wi‑Fi сети. Гостевая сеть с изоляцией устройств не подойдёт.
3. На часах откройте **Настройки → О часах → Сведения о ПО**. Несколько раз нажмите **Версия ПО**, пока не включится режим разработчика. Вернитесь в настройки → **Параметры разработчика** → включите **Отладку по ADB**, если есть такой переключатель, и **Беспроводную отладку**. Разрешите подключение в текущей сети.
4. На Windows запустите `install.cmd` из распакованной папки. На macOS/Linux откройте терминал в этой папке и выполните `bash install-macos-linux.sh`. Установщик сам скачает официальные Android Platform Tools с сайта Google; Android Studio и Java не нужны.
5. На часах выберите **Беспроводная отладка → Подключить устройство с помощью кода**. Введите в установщике IP часов, **порт сопряжения** и шестизначный код. Затем вернитесь на основной экран беспроводной отладки и введите **порт подключения** из строки «IP-адрес и порт». Эти два порта обычно разные. Подтвердите запрос на часах, если появится.
6. После сообщения `Success` удерживайте текущий циферблат → **Добавить циферблат** → найдите **Циферблат Wear OS 1** в конце списка. После установки выключите беспроводную отладку.

В настройках циферблата переключатель **Светлая** меняет тему. В разделе дополнительных элементов выберите источники для **Пульса**, **Погоды** и **Этажей**. Если на часах нет соответствующего источника, поле показывает прочерк. Значения «72», «+4» и «9» из эскиза не подставляются. Шаги, заряд, время и дата обновляются без выбора этих источников. Погода обновляется самим выбранным приложением.

## Если установка не прошла

- `failed to connect` — проверьте порт подключения, Wi‑Fi и включённую отладку. Не используйте порт сопряжения в качестве порта подключения.
- `unauthorized` — подтвердите запрос на часах; при необходимости повторите сопряжение с новым кодом.
- `INSTALL_FAILED_OLDER_SDK` — обновите ПО часов: нужен Android API 33 / Wear OS 4 или новее.
- `INSTALL_FAILED_UPDATE_INCOMPATIBLE` — уже установлена сборка с другой подписью. Не удаляйте её автоматически; сообщите об ошибке, чтобы проверить обновление.
- Циферблата нет в списке — добавьте его через «Добавить циферблат» на самих часах; при необходимости закройте и снова откройте список.

Установщики не меняют системные приложения и не удаляют циферблаты. Они подключаются к указанным вами часам и выполняют установку/обновление одного APK.

Официальное описание сопряжения: [Samsung — Connecting Galaxy Watch over Wi‑Fi](https://developer.samsung.com/sdp/blog/en/2023/11/14/connecting-galaxy-watch-to-watch-face-studio-over-wi-fi).
