ЦИФЕРБЛАТ WEAR OS 1.1.1 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.1.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы по инструкции приложения.
3. Выберите установку APK, укажите скачанный файл и подтвердите установку на часы.
4. Удалять установленный «Циферблат Wear OS 1.1» не нужно: версия 1.1.1 ставится поверх версии 1.1.0.
5. На часах удерживайте текущий циферблат → «Добавить циферблат» → выберите «Циферблат Wear OS 1.1».
6. Откройте «Настроить», назначьте источники пяти секторов и при необходимости выберите подписи.

В ручном списке подписей удалены «ВЫСОТА», «ЭТАЖИ» и «РАССТ.». «ДАВЛЕНИЕ» заменено на «КРОВ. ДАВЛ.». Левый нижний сектор остаётся настраиваемым: в режиме «Авто» он использует название выбранного источника, а если источник не передал название — показывает только значение.

Требование: Wear OS 6 / Android API 36.
