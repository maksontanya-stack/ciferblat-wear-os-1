ЦИФЕРБЛАТ WEAR OS 1.1.5 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.5.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление.
4. Предыдущую версию удалять не нужно: 1.1.5 устанавливается поверх неё.
5. После установки полностью закройте Galaxy Wearable и откройте снова.

Новое в 1.1.5:
• В редактор добавлены «Нажатие: дата» и «Нажатие: минуты».
• У каждой зоны можно выбрать системный источник/приложение. Для даты по
  умолчанию выбран календарный источник; для минут можно выбрать, например,
  таймер. Нажатие запускает действие выбранного источника.
• Размеры зон ограничены соответственно областью даты и областью крупных минут.
• Вид циферблата не изменён: выбранный источник не рисуется поверх даты и минут.

Требование: Wear OS 6 / Android API 36.
