ЦИФЕРБЛАТ WEAR OS 1.1.4 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.4.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление.
4. Предыдущую версию удалять не нужно: 1.1.4 устанавливается поверх неё.
5. После установки полностью закройте Galaxy Wearable и откройте снова.

Исправление 1.1.4: пять видимых светлых внутренних дуг выровнены
математически. От каждой соседней красной метки до дуги оставлен одинаковый
угловой зазор 6°. Сектор даты оставлен без дуги намеренно, чтобы не перекрывать
дату. Добавлена автоматическая проверка этой геометрии.

Требование: Wear OS 6 / Android API 36.
