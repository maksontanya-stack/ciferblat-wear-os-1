ЦИФЕРБЛАТ WEAR OS 1.1.7 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.7.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление.
4. Предыдущую версию удалять не нужно: 1.1.7 устанавливается поверх неё.
5. После установки полностью закройте Galaxy Wearable и откройте снова.

Исправления 1.1.7:
• поле «ШАГИ» использует высоту букв «ПУЛЬС» для обычных значений, включая
  четырёхзначное число; уменьшение остаётся только для действительно длинных;
• зоны «Нажатие: дата» и «Нажатие: минуты» расширены влево до полного
  перекрытия текста, без изменения их правой границы и без наложения друг на
  друга;
• обновлён полный эскиз циферблата для текущей версии.

Требование: Wear OS 6 / Android API 36.
