ЦИФЕРБЛАТ WEAR OS 1.1.6 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.6.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление.
4. Предыдущую версию удалять не нужно: 1.1.6 устанавливается поверх неё.
5. После установки полностью закройте Galaxy Wearable и откройте снова.

Исправления 1.1.6:
• зоны «Нажатие: дата» и «Нажатие: минуты» расширены по отмеченным областям;
• красная линия между датой и минутами сделана тонкой и одинаковой по всей
  сохранённой длине;
• «ТАЙМЕР» возвращён в список ручного выбора подписи;
• для «ЗАРЯД» и «ШАГИ» убран избыточный запас ширины: при обычных значениях
  высота букв сохраняется как у верхнего поля «ПУЛЬС».

Требование: Wear OS 6 / Android API 36.
