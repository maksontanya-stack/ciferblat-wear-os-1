ЦИФЕРБЛАТ WEAR OS 1.1.2 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.2.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление на часах.
4. Версии 1.1.0 и 1.1.1 удалять не нужно: версия 1.1.2 устанавливается поверх них.
5. Откройте Galaxy Wearable → Циферблаты → Циферблат Wear OS 1 → Настроить.

В разделе «Тема» теперь показываются уменьшенные эскизы тёмного и светлого циферблата. В разделах «Подпись» каждый вариант имеет собственную подписанную миниатюру. Главный эскиз обновлён по актуальной шкале: равномерные риски, отметка «20» с четырьмя соседними засечками и действующие подписи.

Если Galaxy Wearable оставил старые миниатюры в кеше, полностью закройте приложение на телефоне и откройте его снова после установки APK.

Требование: Wear OS 6 / Android API 36.
