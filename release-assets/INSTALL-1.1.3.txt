ЦИФЕРБЛАТ WEAR OS 1.1.3 — УСТАНОВКА С ТЕЛЕФОНА

1. Скачайте Ciferblat-Wear-OS-1.1.3.apk на телефон Samsung.
2. Откройте GeminiMan WearOS Manager и подключите часы.
3. Выберите установку APK, укажите скачанный файл и подтвердите обновление.
4. Предыдущую версию удалять не нужно: 1.1.3 устанавливается поверх неё.
5. После установки полностью закройте Galaxy Wearable и откройте снова.

Исправление 1.1.3: восемь наружных засечек правого нижнего сектора скопированы зеркально с правильных левых секторов возле «35» и «40». Удалены ошибочные засечки на 111° и 129°. Рабочий циферблат, основной эскиз и миниатюры редактора используют одну исправленную шкалу.

Требование: Wear OS 6 / Android API 36.
